# Build by Coin Android Lab v0.1

Author: ArchitectZero
Role: Repository Architect

Mobile-first local development/test terminal for Build by Coin.

## v0.1 contract
- Terminal-first portrait UI; full-screen and split landscape runtime views.
- Intake single files or ZIP cartridges.
- Originals are immutable after intake; SHA-256 and byte length are recorded.
- Existing A25 coins are read without rewriting source metadata.
- Unknown facts remain UNRESOLVED.
- New files may produce a candidate coin or be attached sideways to an existing master coin.
- Project assets include images and audio with preview/playback and scale controls.
- PLAY, AUTO and WATCH use the same runtime core.
- Export one file, one coin container, a reusable template, test evidence, or a complete project ZIP.
- Test instrumentation must not become alternate game logic.
- Sample coins bundled with the APK are fixtures only and remain valid A25 artifacts.

## Source layout
- app/ Android application
- runtime/ deterministic runtime contracts
- samples/ packaged sample fixtures
- docs/ frozen v0.1 contracts

The first proof is: import -> inspect -> project -> run -> evidence -> export.
